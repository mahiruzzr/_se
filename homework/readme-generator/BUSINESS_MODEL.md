# 商業價值與使用價值說明

## 1. 使用價值：自己就是使用者

### 痛點（真實且高頻）
- 每個程式設計師每年都要寫 5–20 次 README：課程作業、專題、 side project、接案交付、開源。
- 常見慘狀：只有一句話 + 沒有安裝步驟 + 沒有截圖 + 授權空白 → 老師扣分、業主不敢用、Star 上不去。
- 寫一份好 README 平均 1–2 小時，且多數人不知道「好」的標準是什麼。

### 本專案的解法
- `scan`：自動從程式碼反推語言佔比、框架、安裝/啟動/測試指令、截圖、授權，省掉 70% 打字。
- `init`：3 分鐘問答補齊 tagline、受眾、功能、聯絡方式。
- `check`：0–100 分 + 8 項檢查（標題/徽章/安裝/用法/功能/結構/授權/截圖），把模糊的「寫好一點」變成可執行的待辦清單。
- 4 模板對應真實場景：開源庫 / 接案作品集 / 課程專題 / SaaS，而不是一種版型打天下。

### 為什麼是零依賴？
- 安裝摩擦 = 流失率。`pip install -e .` 或單拷 `src/readme_gen` 即用，離線教室/客戶內網也能跑。
- 這是刻意產品決策，不是技術妥協。

## 2. 商業價值：三條變現路徑

### A. Freemium SaaS（主線）
| 方案 | 價格 | 內容 |
|---|---|---|
| Free（本地 CLI） | $0，開源 MIT | 本專案全部功能，換口碑與 GitHub Star |
| Pro | $9/mo | 雲端版：AI 潤飾、多國語言、徽章/架構圖自動生成、版本歷史、作品集網站一鍵發佈 |
| Team | $29/seat | 團隊文件規範檢查（CI gate：README 分數 <80 擋 PR）、組織模板 |

成本結構：靜態掃描在本地做，雲端只做 AI 潤飾與託管，邊際成本低。

### B. 接案加值包（最快收到錢）
- **作品集代寫 $49/次**：學生/接案者付費一次，拿到 portfolio 模板 README + 一頁業主簡報。
- **交付文件標準化**：接案合約加一條「交付含 80+ 分 README」，用 `check` 做驗收標準，減少尾款糾紛。
- 本工具已內建 `portfolio` 模板的「為什麼選我 / 量化成果 / 接案範圍」三段式，專為成交設計。

### C. 教學市場
- 大學程式課程、補習班、企業內訓：把 `check` 接進作業繳交系統，自動退回低分 README。
- 可收授權費或客製模板費（例如全校統一 course 模板）。

## 3. 為什麼現在做？護城河在哪？

- 通用 AI 能寫 README，但**不會掃你的專案**（語言佔比、真實啟動指令、截圖路徑、授權）， hallucination 嚴重。
- 本專案的護城河 = **掃描器準確度 + 評分標準 + 模板場景化**，AI 是加分項不是本體。
- 已驗證：本機複雜 C++ 混合專案（vendor 目錄、Makefile、images/）可達 100/100 分，無需手動整理。

## 4. 下一步（若要繼續商業化）
1. `readme-gen check` 接 pre-commit / GitHub Action（分數 <80 擋 merge）。
2. 雲端版：貼上 GitHub URL → 線上預覽 + 一鍵 PR。
3. AI 潤飾外掛（可選依賴 `openai`，本地預設關閉，保持零依賴核心）。
